# 01 - Project Overview

## Mission

HalluciShield AI is a multi-agent confidence framework that detects, classifies, and mitigates hallucination-induced software vulnerabilities in code generated by Large Language Models (LLMs).

## Problem Statement

LLMs produce plausible-looking but incorrect code: phantom methods, hallucinated package imports, invalid API signatures, and context-drifted logic. These hallucinations create exploitable security vulnerabilities that traditional static analysis tools miss.

## Key Features

- **Multi-Agent Analysis Pipeline**: Dedicated agents for hallucination detection, security scanning, and dependency validation
- **Adaptive Confidence Engine (ACE)**: Deterministic, explainable confidence scoring with Bayesian weight calibration
- **LLM-Powered Patch Generation**: Automated patch synthesis with sandbox validation
- **Human-in-the-Loop Approval**: Developer gate for patch acceptance/rejection with feedback-driven learning
- **Shared Workspace Architecture**: Secure, per-scan isolated Docker workspace with zip-slip protection
- **Runtime Monitoring**: Post-deployment feedback loop for continuous confidence calibration

## Research Contribution

The ACE calculates a confidence score C in [0,1] for every proposed patch:

```
C = w_hallucination * S_hallucination
  + w_security      * S_security
  + w_dep           * S_dep
  + w_patch         * S_patch
```

Where S_* are domain-specific severity scores and w_* are model weights calibrated over time using developer approval/rejection feedback via Bayesian online updating.

## Target Users

- Security engineers reviewing AI-generated code
- Development teams using LLM code assistants
- Organizations with AI code generation in their CI/CD pipeline
