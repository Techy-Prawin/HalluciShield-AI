# 14 - Hallucination Detection

## Overview

The Hallucination Detection Agent identifies code generated by LLMs that references non-existent APIs, packages, or patterns.

## Detection Categories

### Phantom Methods
Methods called on objects that don't exist in the referenced library/class.

**Example**:
```python
import numpy as np
arr = np.array([1, 2, 3])
arr.nonexistent_method()  # Phantom method
```

### Invalid Imports
Importing packages or modules that don't exist on PyPI/npm.

**Example**:
```python
from nonexistent_package import something  # Invalid import
```

### Signature Mismatch
Function calls with wrong argument types, counts, or names.

**Example**:
```python
def add(a, b):
    return a + b
add(1, 2, 3)  # Too many arguments
```

### Context Drift
Code referencing variables, functions, or classes from wrong scope.

**Example**:
```python
def outer():
    x = 10
    def inner():
        return x  # OK
    return y  # Context drift - y undefined
```

## Detection Strategy

### LLM-Based Analysis

The agent uses Groq API with structured prompts:

1. Read source files from workspace
2. For each file, construct analysis prompt
3. Send to LLM for hallucination classification
4. Parse structured JSON response
5. Map findings to categories

### AST Analysis

`ai-engine/app/analyzer/` provides language-specific parsers:
- `python_parser.py` - Python AST analysis
- `javascript_parser.py` - JavaScript/TypeScript analysis
- `typescript_parser.py` - TypeScript-specific checks
- `java_parser.py` - Java analysis

### Signature Validation

Cross-references function calls against:
- Known library APIs (built-in knowledge)
- Package registry metadata (PyPI/npm)
- Type annotations (when available)

## API Endpoint

```
POST /api/v1/hallucination/detect
```

**Request**:
```json
{
  "repository_id": "uuid",
  "workspace_path": "/workspace/runs/<scanId>"
}
```

**Response** (`DetectionResponse`):
```json
{
  "repository_id": "uuid",
  "findings": [
    {
      "category": "PHANTOM_METHOD",
      "symbol_name": "nonexistent_method",
      "file_path": "src/main.py",
      "line_number": 15,
      "snippet": "arr.nonexistent_method()",
      "confidence": 0.95,
      "raw_details": {}
    }
  ],
  "total_findings": 1,
  "analysis_duration_ms": 1200
}
```

## Security

- `validate_workspace_path()` called before any file access
- Path traversal (`..`) rejected
- When `HALLUCISHIELD_WORKSPACE_ROOT` set, restricted to workspace root
